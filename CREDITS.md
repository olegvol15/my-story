# Credits

## Letter Glitch background

`src/components/LetterGlitch.astro` is a port of the **Letter Glitch** component
from [React Bits](https://reactbits.dev), adapted from React to a vanilla Astro
component. The canvas logic, glitch cycle and colour interpolation follow the
original; the port adds tab-visibility pausing, a device-pixel-ratio cap and
`prefers-reduced-motion` support.
